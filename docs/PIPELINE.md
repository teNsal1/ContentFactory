ContentFactory — Production Pipeline

Goal

Generate a vertical YouTube Shorts video (9:16, 30–60 seconds) from a single topic.

Pipeline

1. Topic input
2. English script generation
3. Voiceover generation
4. Visual asset preparation
5. Subtitle generation
6. Video assembly with FFmpeg
7. Export final MP4
8. Manual review before publishing

Constraints

* Initial budget: 0 RUB
* Development device: iPhone
* Main production device: Windows PC
* Prefer free and local tools
* Avoid paid subscriptions until the free workflow is tested
* Never claim a stage is automated until it has been tested

First MVP

Start with a working pipeline using still images, voiceover, subtitles, and FFmpeg. Investigate AI video generation later.
